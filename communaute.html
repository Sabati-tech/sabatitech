💡 Astuce : Script PowerShell pour lister tous les services
Voici une commande utile que j'utilise souvent pour lister les services Windows avec leur statut :
powershell
Get-Service | Where-Object {$_.Status -eq "Running"} | Select-Object Name, Status | Sort-Object Name
